# System-Based website: CDN files

This branch only holds the built website files that the GoHighLevel code block loads
through jsDelivr. It is kept tiny on purpose: jsDelivr will not serve a GitHub commit
whose files total more than 50 MB, and the main branch is larger than that.

Do not edit these files by hand. They are generated by `npm run build:ghl-dropin` on the
website branch; see `ghl/README.md` there for the release steps.
