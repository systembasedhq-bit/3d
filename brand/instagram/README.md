# System-Based on Instagram (@systembasedhq)

Same look as systembased.net: obsidian black, polished chrome, Michroma headlines,
mono labels and the chrome SB monogram. Everything here is rendered from the website's
own tokens, copy and client data, so it stays in step with the site.

Render again any time: `npm run brand:instagram` (outputs to `brand/instagram/out/`).
`out/ready/` holds everything numbered in posting order.
